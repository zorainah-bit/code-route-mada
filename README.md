# Code de la route — Madagascar

Application Android (APK) pour apprendre le code de la route malagasy.

## Fichiers du dépôt

| Fichier | Description |
|---------|-------------|
| `index.html` | Page d’accueil GitHub Pages (décor route Antananarivo + bouton téléchargement) |
| `code-de-la-route-madagascar.apk` | **Application Android** (à uploader dans le dépôt) |

## GitHub Pages

1. Uploadez `index.html` + votre fichier `.apk` (même nom : `code-de-la-route-madagascar.apk`)
2. Settings → Pages → Deploy from branch (`main`, `/ root`)
3. URL : `https://VOTRE-USER.github.io/VOTRE-REPO/`

Le bouton **Telechargeo ny APK** en haut télécharge directement le fichier APK.
